# DriftDS

A native PC port of Mario Kart DS. No game data is included in this repository.

Work in progress

Foundations by [DS Kart Recompiled](https://github.com/AlonsoTlol/DS-Kart-Recompiled) by alontube. The recompiler and the runtime were reworked from that project (Thanks!!).

Not affiliated with or endorsed by Nintendo. Mario Kart and Nintendo DS are trademarks of Nintendo. A Mario Kart DS ROM that you own is needed to build and play.
